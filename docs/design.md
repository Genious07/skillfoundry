# SkillFoundry design plan

The main surface aligns a source example, a candidate procedure and a challenge.
This is a catalog specialist's pattern workshop. The visual identity is an open
woven S: two offset strands meet at a square junction while a deliberate gap
represents the condition where a rule must stop and request context.

Palette: aubergine ink #352744, pattern lilac #F1EDF6, sheet white #FFFFFF,
working violet #6B42A1, proven green #22664E, boundary amber #8A5415.
Typography: locally bundled Literata for the procedure title; IBM Plex Sans for
controls, source rows and numerical evidence. Tabular numerals preserve alignment.

Layout, left aligned:

    brand / unit normalization                     evaluation action
    source example       candidate procedure       challenge case
    saved corrections / immutable evaluation history
    supplier-separated evidence / case outcomes / gate criteria

A generic dashboard would hide the decisive distinction between 12 items and
12 mm in a card. The central surface instead keeps those literal source values
beside the rule boundary. Source is white, an unevaluated candidate lilac, and a
challenge has a clear border. Green appears only after the server's evaluation.

The UI reports fixture evidence, never learned intelligence. Manual templates are
labeled as such. Saving a correction records an event; it does not secretly edit
expected labels or invent a model proposal. Tablet collapses to two columns and
mobile stacks example, rule and challenge in reading order. Keyboard focus and
44px controls are required. Motion is limited to loading and user actions.
